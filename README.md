# PPB_TESTER

Историческая монолитная версия ПО испытаний ППБ. Поддерживаемая модульная линия — [PPB_Project](https://github.com/Anatolichka2202/PPB_Project).

## Состав

- `core/` — приложение, обмен, утилиты, логирование и работа с генератором.
- `analyzer/` — анализ пакетов.
- `gui/` — пульт и интерфейс тестера.
- `scenarios/`, `resources/` — сценарии и ресурсы.

Объявленные зависимости: CMake 3.16+, C++17, Qt Widgets/Network; аппаратная USB-обвязка использует Windows CH375 SDK. Поставляемые SDK-файлы не являются сборочным мусором.

Перед архивированием сохраняются полезные отличия относительно PPB_Project. Сборка и аппаратные испытания в рамках оформления не выполнялись.
